# Windows 桌面版

桌面版面向 Windows x64，包含 Java 25 运行时，使用时无需安装 Java、Node 或开发工具。词典单独导入；没有词典也能启动并管理歌曲和个人词库。

## 安装与升级

运行 LyricVocabularyBuilder-Setup-1.0.0.exe，按向导安装。安装位置固定为当前用户的程序目录。用户数据保存在 %LOCALAPPDATA%\\LyricVocabularyBuilder，升级安装保留这些数据。升级前可在数据管理页导出完整 JSON 备份。

## ZIP 便携版

将 LyricVocabularyBuilder-Portable-1.0.0.zip 完整解压到可写目录，再启动 LyricVocabularyBuilder.exe。保持 portable.flag 与程序同目录；应用数据保存在同目录的 user-data 文件夹。整体移动便携目录时同时保留 user-data。目录不可写时应用会报错并退出。

新版便携包解压到新目录，通过完整备份与恢复迁移。安装版与便携版之间也使用同一备份流程。

## 词典

首次启动显示欢迎说明，可选择“前往设置”或“关闭”。关闭后会记住选择；“前往设置”打开设置页顶部。

设置页的“词典数据”提供“下载”“打开目录”“重新扫描”“选择其他文件”四个入口，标题旁的信息提示说明配置步骤。“下载”打开[LyricVocabularyDictionary 词典数据发布页](https://github.com/EachYoungX/LyricVocabularyDictionary/releases)。解压后将 dictionary.sqlite 移入默认词典目录，点击“重新扫描”；尚未启用词典且默认目录只有一个有效数据集时，会自动启用。多个有效数据集需要手动选择。默认目录中的词典可随便携应用整体移动。

外部词典直接引用原文件。移动、重命名或删除原文件后，需要重新选择。取消引用保留原文件。删除托管词典会要求确认，并仅删除应用管理的副本。完整 JSON 备份包含业务数据，词典文件需另行保存。

## 局域网

默认仅本机可访问。在主机设置页启用局域网后，可通过显示的地址在同网设备访问。后端没有认证，仅在可信私人局域网启用。手机浏览器的原生文件与主机配置操作需回到桌面应用完成。

## 清理与卸载

数据管理页的“清除全部本地数据”清空业务数据及设置。桌面版同时恢复默认词典引用、关闭局域网、清理浏览器存储和临时缓存并重启；托管词典文件保留，可重新发现使用。

卸载默认保留数据，重装后继续使用。选择“同时删除本地数据”并确认警告后，会删除固定用户数据目录，包含托管词典。外部词典、用户另存的备份及其他便携目录保留。

## 故障定位

启动失败时查看提示及数据目录 logs/backend.log。便携版需先完整解压，并确保目录可写。正式发布验收包括安装、升级、卸载及中文和空格路径测试。
